# El Rawda Elshrifa – Import & Export Landing Page

A modern, responsive landing page for **El Rawda Elshrifa**, an import and export company. The website presents the company's business profile, product categories, global trade services, and contact information through a clean and professional interface.

## ✨ Features

- **Responsive Design:** Optimized layouts for desktop, tablet, and mobile devices.
- **Modern Navigation:** Responsive navigation menu with a dedicated mobile menu.
- **Company Overview:** Introduction to the company and its business activities.
- **Product Showcase:** Organized presentation of product categories.
- **Global Trade Services:** Highlights sourcing, logistics, customs clearance, and delivery services.
- **Interactive Navigation:** Active navigation links based on the currently visible section.
- **Smooth Scrolling:** Smooth transitions between page sections.
- **Contact Integration:** Direct communication through phone, WhatsApp, and email.
- **Modern UI:** Custom styling, hover effects, gradients, and typography.

## 🛠️ Technologies Used

- **HTML5** – Semantic page structure.
- **Tailwind CSS v4** – Utility-first styling and responsive layouts.
- **Vanilla JavaScript** – Interactive elements and navigation behavior.
- **Custom CSS** – Additional styling and visual enhancements.
- **Font Awesome 6** – Icons.
- **Google Fonts** – DM Sans and Playfair Display.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)

### Installation

1. Clone the repository:

```bash
git clone https://github.com/joo877/el_rawda_elshrifa_landing_v2.git
```

2. Navigate to the project directory:

```bash
cd el_rawda_elshrifa_landing_v2
```

3. Install dependencies:

```bash
npm install
```

### Development

Start the Tailwind CSS development process:

```bash
npm run dev
```

This command watches the source files and automatically updates the generated CSS.

In another terminal, serve the project locally using a static development server, such as:

```bash
npx serve .
```

### Production Build

Generate the optimized production CSS:

```bash
npm run build
```

The generated stylesheet will be available at:

```text
dist/output.css
```

## 📌 Configuration Notes

Before deploying the website, make sure to:

- Replace placeholder phone numbers and WhatsApp contact details.
- Update the email address with the company's official email.
- Replace placeholder social media links.
- Verify product information and testimonial content before publishing.
